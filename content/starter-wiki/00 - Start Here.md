## Use

- In **Obsidian**, open this folder as a vault to browse the `[[wiki links]]`. Markdown remains plain text you control.
- Keep material in `research`, `draft`, or `proposed` status until you explicitly decide it is part of the world.
- When a detail is canonized, note it in [[Decision Log]], then update the page status.
- For new ChatGPT conversations, upload the relevant `.md` pages or the refreshed vault ZIP. A local vault **does not become automatically visible** to ChatGPT.
- Consider versioned backup copies of this folder in a separate location. Cloud sync is not the same as a backup.
