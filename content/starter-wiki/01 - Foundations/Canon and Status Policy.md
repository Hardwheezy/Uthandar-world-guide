# Canon and Status Policy

This project is especially vulnerable to the accidental promotion of suggestions into facts. Use a status for every article.

| Status | Meaning |
| --- | --- |
| `canon` | Explicitly agreed as part of this world. |
| `draft` | Working description, not yet ratified. |
| `proposed` | Possible direction under consideration. |
| `research` | External material, source notes, or cultural inspiration; **not** automatically setting lore. |
| `reference` | Workflow and documentation rules. |
| `rejected` | Preserved for provenance; not part of the setting. |

**World name and naming approach are now canon:** [[Uthandar - World Overview]] records the explicitly confirmed world name and decision not to assign the continent a universal name at this stage. All other setting notes remain drafts, proposals, or research unless explicitly approved.

When a decision is made:
1. Record the exact decision and date in [[Decision Log]].
2. Change the relevant page to `canon` if appropriate.
3. Add links to affected articles.
4. Preserve contradictory earlier drafts with a note rather than quietly erasing provenance.

Never silently mix content from *Forsaken Gods*, Warcraft, or historical cultures with the original setting.
