# Sea Peoples Pantheon Notes

*Research / working pantheon, not confirmed canon.*

| Deity | Domain / association |
| --- | --- |
| **Rangava** | Sky father; sun, cosmic order, celestial authority, ancestors |
| **Whenua** | Earth mother; land, fertility, birth, crops, herds, homeland |
| **Moanui** | Water goddess; currents, deep water, ocean |
| **Tawaro** | Weather; storms, lightning, thunder, rain |
| **Haurangi** | Wind, sailing, inspiration, breath, speech |
| **Marama** | Night sky, moon, stars, navigation, dreams, hidden knowledge, cycle of time |
